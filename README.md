# Astro Companion

Create a modern responsive website called AstroLive AI Companion.

Tagline:

Your daily personalized astrology companion.

Create these 5 pages:

1. Landing Page

2. Birth Details Page

3. AI Astro Dashboard

4. AstroAI Chat

5. Shareable Astro Card

Use a beautiful modern cosmic design with dark navy, purple and blue colors, stars, gradients and rounded cards.

The website should be mobile-friendly.

Landing page:

- AstroLive AI Companion

- Your daily personalized astrology companion

- Get My Astro Card button

- Explore AstroAI button

Birth Details:

- Name

- Date of Birth

- Time of Birth

- Place of Birth

- Generate My Astro Card button

Dashboard:

- Today's Overview

- Career

- Relationships

- Finance

- Well-being

- Daily Focus

- Lucky Number

- Lucky Color

- Ask AstroAI button

- Share My Astro Card button

AstroAI Chat:

- Chat interface

- Question input

- Send button

- Sample AI responses

Shareable Astro Card:

- User name

- Today's Focus

- Energy

- Lucky Number

- Lucky Color

- Share My Card button

Make all navigation buttons work.

This is a prototype, so use sample/simulated AI responses.

No login or database is required.
